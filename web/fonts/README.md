# Locally bundled typefaces

These are unmodified font files from the Google Fonts repository, downloaded November 16, 2026. Each accompanying OFL notice includes its copyright and redistribution terms.

| Local file | Source | Use |
| --- | --- | --- |
| RussoOne-Regular.ttf | https://github.com/google/fonts/tree/main/ofl/russoone | Heavy headings and MechWarrior wordmark |
| RobotoCondensed-Regular.ttf | https://github.com/google/fonts/tree/main/ofl/robotocondensed | Variable-weight condensed body and interface text |
| Orbitron-Regular.ttf | https://github.com/google/fonts/tree/main/ofl/orbitron | Variable-weight Revived wordmark and compact numerical labels |

They are visual alternatives inspired by the Dark Age print material, not the original proprietary typefaces. No font files were extracted from the original rulebooks. They load locally, including when the site is used offline.
